What goes in the code

Pick what you are sharing — the right prefix is added for you, so the phone opens the dialler, WhatsApp or the payment app instead of showing raw text.

How it looks

Dark code on a light background, always — inverted codes fail on many phones. Higher error correction makes the code denser but lets it scan when creased or printed small.

A sheet of codes

One per line. Add a label after a | or a tab — paste straight from Excel and the second column becomes the caption. Useful for a QR per student, per classroom door, or per fee link.

Up to 200 lines. Blank lines are skipped.

Student Master

This is the single list of students shared by every report app and office tool on this device. Upload it once at the start of the year, add a student mid-year here, and ID cards, certificates, fee statements and student files all just have them — no re-uploading the same names into each tool. Students you upload anywhere else are collected into this list automatically.

ID Cards →Print identity cards straight from this roster. Certificates →Bonafide, transfer and character certificates. Student File →Everything for one student as a single PDF. Fees & Dues →Seed the fee ledger with these students.
